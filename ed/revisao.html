1. TAD e representação por nós

Tipo Abstrato de Dados (TAD) é um conjunto de dados acompanhado das operações permitidas sobre esses dados.

O que o usuário da classe enxerga?

  • Os métodos disponíveis, como inserir, retirar, consultar e percorrer.
  • O comportamento da estrutura.
  • Não precisa conhecer cada alteração de ponteiro internamente.

Nó simples

class No:
    def __init__(self, valor):
        self.valor = valor
        self.proximo = None

Cada nó guarda um valor e uma referência para o próximo nó.

Item importante Uma referência que deveria apontar para outro nó, quando alterada incorretamente, pode perder parte da estrutura ou gerar laço infinito em listas circulares.

2. Pilha — LIFO

Na pilha, o último elemento inserido é o primeiro removido. Inserções e remoções sempre acontecem no topo.

Topo→30→20→10→ None
OperaçãoFunçãoAlterações essenciais
push(valor)Insere no topo.Novo nó aponta para o topo antigo; topo passa a ser o novo nó; incrementa tam.
pop()Remove do topo.Guarda o valor; topo = topo.prox; decrementa tam.
vazia()Consulta se não há itens.Verifica topo is None.
__len__()Obtém tamanho.Retorna tam.

Padrão fundamental: usar pilha auxiliar e restaurar

Para contar, buscar, somar ou remover uma ocorrência sem destruir os dados, retire elementos para uma pilha auxiliar e, depois, devolva-os.

def somar_pilha(pilha):
    aux = Pilha()
    soma = 0

    while not pilha.vazia():
        x = pilha.pop()
        soma += x
        aux.push(x)

    while not aux.vazia():
        pilha.push(aux.pop())

    return soma
Pratique

Funções cobradas no material

  • Contar elementos e contar ocorrências.
  • Copiar mantendo a ordem.
  • Buscar valor sem alterar a pilha.
  • Inserir na base.
  • Remover primeira ocorrência.
  • Comparar duas pilhas.
  • Testar palíndromo.
Atenção

Ordem na cópia e inversão

Transferir diretamente de uma pilha para outra inverte a ordem. Para copiar mantendo a ordem, geralmente é necessária uma pilha auxiliar intermediária.

Exemplo: se o topo de p1 é 30, copiar diretamente faz 10 terminar no topo de p2.

Problema integrador: embaralhar duas pilhas

O material trabalha a intercalação de duas pilhas de tamanhos diferentes, mantendo p1 e p2 intactas e produzindo p3.

P1: A B C D+ P2: 1 2⇒ P3: A 1 B 2 C D
O que não pode acontecer Um laço que retira de uma pilha auxiliar e coloca novamente na mesma pilha nunca termina. Para restaurar, o pop() da auxiliar deve ser enviado à pilha original.

3. Fila — FIFO

Na fila, o primeiro a entrar é o primeiro a sair. Insere-se no fim e remove-se do inicio.

Início→10→20→30→Fim
OperaçãoO que fazCaso crítico
insere(valor)Coloca um novo nó no final.Se vazia, inicio e fim recebem o mesmo nó.
retira()Remove o primeiro nó.Ao retirar o único elemento, também definir fim = None.
frente()Consulta o primeiro valor sem remover.Tratar fila vazia.
esta_vazia()Verifica ausência de nós.inicio is None.

Padrão de preservação na fila

Uma fila auxiliar permite processar todos os itens e recolocá-los na mesma ordem original, pois retirar e inserir em fila preserva a sequência.

def somar_fila(fila):
    aux = Fila()
    soma = 0

    while not fila.esta_vazia():
        x = fila.retira()
        soma += x
        aux.insere(x)

    while not aux.esta_vazia():
        fila.insere(aux.retira())

    return soma
Exercícios-chave
  • Enfileirar e desenfileirar.
  • Consultar a frente e o tamanho.
  • Simular atendimento.
  • Somar e contar ocorrências mantendo a fila.
  • Remover a primeira ocorrência.
  • Verificar se duas filas são iguais.
Pegadinha

Em uma fila, “primeira ocorrência” significa a primeira encontrada começando pelo inicio. Ao remover apenas essa ocorrência, todos os demais itens devem continuar na mesma ordem.

4. Lista simplesmente encadeada

Diferentemente de pilha e fila, a lista não possui uma única regra de entrada e saída: pode inserir e remover no início, no final, após um alvo ou em ordem crescente.

3→5→7→10→ None
MétodoLógica principalReferência alterada
adicionar_no_inicioNovo nó antecede o antigo primeiro.novo.proximo = topo; topo = novo.
adicionar_no_fimPercorre até encontrar o último.ultimo.proximo = novo.
adicionar_aposLocaliza valor-alvo e encaixa o novo nó.Duas referências: novo aponta ao próximo; alvo aponta ao novo.
remove_noLocaliza valor e “pula” o nó removido.Se for primeiro, altera topo; senão, altera anterior.proximo.
insere_ordenadoEncontra a posição crescente correta.Insere antes do primeiro maior ou igual.
percorrerVisita os nós até None.Pode usar yield para entregar valores.

Inserção ordenada: raciocínio que deve dominar

def insere_ordenado(self, valor):
    novo = No(valor)

    if self.topo is None or valor < self.topo.valor:
        novo.proximo = self.topo
        self.topo = novo
        self.tam += 1
        return

    atual = self.topo
    while atual.proximo is not None and atual.proximo.valor < valor:
        atual = atual.proximo

    novo.proximo = atual.proximo
    atual.proximo = novo
    self.tam += 1
Itens importantes Saiba percorrer a lista para: contar elementos sem usar tam, encontrar maior/menor valor, verificar se contém um número, somar valores e exibir em ordem inversa usando uma estrutura auxiliar.

5. Lista duplamente encadeada

Cada nó aponta para o próximo e para o anterior. A estrutura mantém referências para cabeca e cauda, permitindo percurso nos dois sentidos.

None←10⇄20⇄30→None
Vantagem

Percurso reverso

Começa na cauda e avança por anterior. É mais direto do que criar uma cópia apenas para exibir ao contrário.

atual = self.cauda
while atual is not None:
    yield atual.valor
    atual = atual.anterior
Cuidado

Duas conexões

Inserir ou remover no meio exige atualizar os dois sentidos. Não basta alterar o proximo; também é obrigatório ajustar o anterior.

Remoção: quatro casos obrigatórios

CasoCondiçãoAjustes principais
Único nóSem anterior e sem próximo.cabeca = None e cauda = None.
Primeiroanterior is None.Nova cabeça é o próximo; seu anterior = None.
Últimoproximo is None.Nova cauda é o anterior; seu proximo = None.
MeioPossui vizinhos dos dois lados.Vizinho anterior aponta ao próximo e vice-versa.

6. Lista circular

Na lista circular, não há último nó apontando para None: a cauda.proximo deve apontar novamente para a cabeca.

Cabeça: 10→20→Cauda: 30↺ cabeça
Invariante

Regra que nunca pode quebrar

Quando a lista não está vazia, sempre deve valer:

self.cauda.proximo == self.cabeca
Laço

Critério de parada

Como nenhum nó aponta para None, percorrer até None gera loop infinito. Deve-se parar ao retornar à cabeça.

while True:
    ...
    atual = atual.proximo
    if atual == self.cabeca:
        break

Operações críticas

OperaçãoO que observar
Inserir no inícioAtualizar cabeca e fazer cauda.proximo apontar à nova cabeça.
Inserir no fimNovo nó aponta para a cabeça; a cauda anterior aponta ao novo; atualizar cauda.
Remover único nóDefinir cabeça e cauda como None.
Remover a cabeçaNova cabeça deve continuar sendo alcançada pela cauda.
Remover a caudaAnterior vira cauda e precisa voltar a apontar à cabeça.
Inserção ordenadaTratar separadamente vazio, antes da cabeça, depois da cauda e meio.

7. Algoritmos de ordenação

O material apresenta cinco algoritmos. Memorize a ideia principal, a forma como reorganizam valores e o cenário em que fazem sentido.

AlgoritmoComo funcionaImagem mentalUso indicado no material
Bubble Sort Compara vizinhos e troca quando estão fora de ordem. O maior “flutua” para o fim a cada passada. Listas pequenas ou quase ordenadas.
Selection Sort Escolhe o menor restante e o posiciona no início da parte não ordenada. Selecionar o próximo menor. Listas pequenas com custo alto de movimentação.
Insertion Sort Insere cada elemento na posição correta da parte já ordenada. Organizar cartas na mão. Conjuntos pequenos.
Merge Sort Divide a lista, ordena partes e mescla em ordem. Dividir e conquistar, depois juntar. Listas grandes; desempenho garantido e estabilidade.
Quick Sort Escolhe pivô, separa menores/maiores e repete recursivamente. Particionar ao redor do pivô. Ordenação interna rápida em ampla variedade de situações.
Possível questão Dado um pequeno conjunto de números, descreva uma passada do Bubble Sort, Selection Sort ou Insertion Sort, ou escolha um algoritmo e implemente em Python.

9. Pontos de atenção e erros comuns

Além dos conceitos, revise estes detalhes: são fontes comuns de perda de pontos em implementação.

Tamanho

Atualize tam

Toda inserção bem-sucedida incrementa e toda remoção bem-sucedida decrementa. No trecho de lista simples do material, o método remove_no precisa decrementar self.tam após remover.

Fila vazia

Remover o único elemento

Após inicio = inicio.proximo, se o início virou None, o fim também deve virar None.

Pilha vazia

Consulta do topo

Antes de executar return self.topo.valor, trate o caso de pilha vazia para evitar erro de acesso a None.

Circular

Não percorra até None

Na lista circular, pare ao reencontrar a cabeça. Sem isso, o programa não encerra o percurso.

Ordem

Auxiliar correta

Em pilhas, mover itens altera a ordem; em filas, rotacionar por retirada e inserção preserva a ordem. Faça testes com três valores para confirmar.

Código

Revise sintaxe e variável exibida

No material, o exercício contem tem um else sem dois-pontos; no exercício de menor valor, deve ser mostrado menor, não o último numero percorrido.

Regra de ouro Quando o enunciado disser que a estrutura deve permanecer intacta, mostre mentalmente o estado antes e depois. A resposta só está correta se valores e ordem forem preservados.

11. Questões de revisão rápida

Tente responder antes de revelar a solução.

1. Ao inserir 10, 20 e 30 em uma pilha, nessa ordem, qual valor será retornado pelo primeiro pop()?

30. A pilha segue LIFO: o último inserido é o primeiro removido.

2. Em uma fila com 10 → 20 → 30, qual valor sai em retira() e qual fica na frente?

Sai 10; após a remoção, 20 passa a estar na frente.

3. Por que copiar diretamente de uma pilha para outra costuma inverter a ordem?

Porque o topo da pilha original é retirado primeiro e também se torna o primeiro item inserido; com novas inserções acima dele, termina mais abaixo na pilha destino.

4. Qual referência obrigatoriamente deve ser mantida em uma lista circular não vazia?

cauda.proximo == cabeca. Essa referência fecha o ciclo.

5. Quais são os quatro casos ao remover um nó de uma lista duplamente encadeada?

Remoção do único nó, do primeiro nó, do último nó e de um nó do meio.

6. Qual algoritmo compara elementos adjacentes e qual usa pivô?

Bubble Sort compara adjacentes; Quick Sort utiliza pivô.
